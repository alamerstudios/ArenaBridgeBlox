# ArenaBridgeBlox

Landingpage für den Arena AI Roblox Studio Bridge-Download.

## Lokal ansehen

Die Seite ist statisch und benötigt keinen Build-Schritt. `index.html` direkt im Browser öffnen oder zum Beispiel `python -m http.server 8000` im Repository starten.

Der Download-Button verweist auf den Arena Studio Connector Portable 2.0.1 (Windows x64):
`https://raw.githubusercontent.com/alamerstudios/ArenaBridgeRoblox/v2.0.1/downloads/Arena-Studio-Connecter-Portable-2.0.1-x64.exe`
